The gateway reads one configuration file, `config.yaml` in this documentation, when it starts: `slay400-gateway run --config config.yaml`. It is YAML, at most 1 MiB, in UTF-8. The gateway checks the whole file before it listens, reports every problem with its line and column and a code from GWY001 to GWY009 or GWY015, and does not start while one is left; `slay400-gateway check --config config.yaml` does the same and exits. A change to the file takes effect at the next start; bundles and certificate files are taken without a restart (see `reload`).

A value can be, or contain, a `${NAME}` placeholder: the gateway puts in the value of the environment variable `NAME` at start, and stops with GWY007 if it is not set. Credentials and the key password must be exactly one placeholder (GWY015): a value written in the file is refused.
