The invented program `TSTNESTED` of `ibmi/programs`, from its source to an answer through the gateway, with `TSTNONE`, an overlay for a program that is never created. `input/apis/` holds the PCML the compiler wrote for `TSTNESTED` on the test system (with the user of its source path written `<user>`), so that the steps after the compile run without an IBM i. The regions marked `# requires: ibmi` are not run by the build: the manual `ibmi` workflow runs them (all but `compile` and `credentials`, whose work its setup and its secrets do, and `sign-on-refused`, whose recording `SignOnRefusedRecordingTest` of `gateway-ibmi` makes with a fake connection, so that no run signs on with a wrong password) and records their output. Used by the page Call a program on IBM i (`/docs/tutorials/call-a-program-on-ibm-i/`); its region `add-jt400` is the snippet "Add JT400".
