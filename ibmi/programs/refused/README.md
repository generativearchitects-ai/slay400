# Refused by the compiler

Probe programs of kickoff 05 that the RPG compiler did not compile, in run 1 of that increment: a date field in `*LONGJUL`,
`*CYMD`, `*CMDY` and `*CDMY` as a program parameter. Each ended with `RNS9308 Compilation stopped. Severity 20 errors found
in program.` and `RNS9310 Compilation failed.` These formats stay refused by the gateway. The sources are kept as the record;
the setup tool does not compile them.
